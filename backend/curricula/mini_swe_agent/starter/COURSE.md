# Build mini-swe-agent

This course has 39 individual tasks. Each task implements the named functions
or methods in its brief. Later helpers may remain unfinished: acceptance checks
isolate dependencies that have not been taught yet. Every task has a separate
Learn the concept page with examples, explanations, and a return link.

Start with the model class and conversation behavior, then build tools,
autonomous repairs, containers, reliability, memory, and security.

Nudge supplies the starter files, execution environment, and dependencies.
You do not need to create a virtual environment, install packages, or write
project setup code. Focus on the agent logic in the named task targets.

Provider completions and Docker CLI calls are injected during checks. Keep
credentials outside learner files and command environments. No provider key or
host Docker socket is exposed to the sandbox. Tenacity is preinstalled.

Use Check task after each implementation. Run opens a scripted repair viewer
using your completed shell, tools and autonomy components. The viewer explains
which components are still unfinished. A real provider/Docker trial requires
a separately configured exported development environment.
